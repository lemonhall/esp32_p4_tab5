# PRD-0001: Tab5 竖屏 IRC Client（v1）

## Vision
在 M5Stack Tab5（ESP32‑P4）上做一个“竖屏 IRC 客户端”：**能上网、能进频道、能稳定滚动显示中文消息、能一键发测试消息**，并预留语音输入（ASR）入口按钮，为后续 ASR/TTS 迭代打底。

## Background / Constraints
- 平台：Windows 11 + PowerShell 开发；固件基于 `M5Tab5-UserDemo` 技术栈（ESP‑IDF + LVGL + mooncake/smooth_ui_toolkit）。
- 网络：P4↔C6 走 `esp_hosted`/`esp_wifi_remote`，业务层用 `esp_wifi/esp_netif` API。
- 方向：竖屏（现有 Demo 已对显示做 90° 旋转）。
- 输入：v1 不做屏幕软键盘中文输入；发消息仅做“固定测试消息”按钮；保留“语音输入”按钮（仅 UI 占位）。
- 中文显示：v1 采用 **SD 卡 `font.ttf`** 方案（运行时加载字体），避免固件内置大字库。
- IRC：v1 只做明文 TCP（无 TLS）。

## Non-goals（v1 明确不做）
- 不做 TLS（6697）与证书校验
- 不做 SASL / NickServ 登录
- 不做多服务器/多频道管理
- 不做屏幕软键盘/文本输入框
- 不做表情/彩色控制码完整支持（只保证 UTF‑8 文本可读）
- 不做离线消息缓存/历史回放

## Requirements

### REQ-0001-001：Wi‑Fi 配网（无需板子端键盘）
**描述**：Tab5 开机进入“配网/自愈”模式：如果没有可用的 STA 配置或 STA 连接失败超时，则开启 SoftAP，并提供网页表单填写 SSID/密码；填写后保存到 NVS，并尝试 STA 连接上网。  
**验收**：
1) 首次开机（NVS 无配置）时能看到 SoftAP SSID；手机/电脑连接后可在浏览器打开 `http://192.168.4.1` 看到配置页。  
2) 提交 SSID/密码后，串口日志出现“已保存配置”“开始 STA 连接”。  
3) STA 成功后串口日志出现“STA 已连接 + 拿到 IP”。  

### REQ-0001-002：SoftAP 关闭与断线自愈
**描述**：STA 成功连接并稳定后关闭 SoftAP；若 STA 掉线持续超过 N 秒（默认 30 秒），自动回到 SoftAP 配网模式。  
**验收**：
1) STA 成功后 SoftAP 不再可见（AP 关闭）。  
2) 人为断开路由器或改错密码导致持续掉线时，30 秒后 SoftAP 重新出现。  

### REQ-0001-003：NICK 自动生成（≤ 9 字符）与冲突重试
**描述**：IRC NICK 自动生成，长度不超过 9；若服务器提示 NICK 冲突，则自动重试（不弹键盘）。  
**验收**：
1) 串口日志打印最终 NICK，长度 ≤ 9。  
2) 人为让 NICK 冲突时，能看到“重试第 n 次”的日志，最终进入连接成功状态或明确失败。  

### REQ-0001-004：中文显示（SD 卡 `font.ttf`）
**描述**：若 SD 卡根目录存在 `font.ttf`，应用加载该字体并用于 IRC 消息显示，能正确显示中文。  
**验收**：
1) 插入含 `font.ttf` 的 SD 卡后，串口日志出现“字体加载成功”。  
2) IRC 收到中文消息时屏幕可读显示（不是方框）。  
3) 若无 SD 或无 `font.ttf`，应用提示缺失并降级到默认字体（可显示英文）。  

### REQ-0001-005：连接 IRC（明文 TCP）并自动加入频道
**描述**：连接 `irc.lemonhall.me:6667`，完成 IRC 握手（NICK/USER）并自动 `JOIN #tab5`。  
**验收**：
1) 串口日志出现“socket connected”“sent NICK/USER”“JOIN #tab5”。  
2) 处理 `PING` 并正确回 `PONG`，保持连接不断开（至少 5 分钟）。  

### REQ-0001-006：竖屏消息显示 + 固定测试消息发送
**描述**：竖屏窗口显示 IRC 文本流（至少包含 PRIVMSG 与关键系统行）；提供“发送测试”按钮，一键向 `#tab5` 发送固定测试消息（例如 `hi from <nick>`）。  
**验收**：
1) 屏幕能持续滚动显示新消息。  
2) 点击按钮后串口日志出现“PRIVMSG #tab5 :hi from …”。  

### REQ-0001-007：语音输入按钮（占位）
**描述**：在 IRC 窗口底部提供“语音”按钮，仅做 UI 占位（点击只弹 toast 或无动作）。  
**验收**：按钮可见、可点击且不会导致崩溃。

## Metrics（v1 可量化目标）
- 从开机到进入“可配网/可连接”的 UI：≤ 8 秒（不含首次配网的人为操作）
- IRC 消息区持续滚动 5 分钟无崩溃、无明显卡死
